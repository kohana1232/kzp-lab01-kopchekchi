## 2. Постановка завдання

Відповідно до варіанта 11 необхідно розробити консольну програму для обробки даних аптеки.

Кожен запис містить п'ять полів:

- `name` — назва препарату (String);
- `form` — форма препарату (String);
- `price` — ціна (double);
- `daysToExpire` — кількість днів до завершення терміну придатності (int);
- `prescription` — ознака рецептурності (boolean).

Програма повинна обчислювати чотири показники:

1. Кількість коректних записів.
2. Середню ціну препаратів.
3. Мінімальну кількість днів до завершення терміну придатності.
4. Кількість рецептурних препаратів.

Некоректні записи необхідно пропускати з повідомленням про номер рядка та причину помилки.

## 4. Хід виконання роботи

### 4.1. Підготовка середовища

Встановлено JDK 21 та налаштовано середовище Visual Studio Code для роботи з Java.

Під час першого запуску виявлено конфлікт версій: компілятор `javac` використовував Java 21, а команда `java` — Java 8.

Після зміни порядку шляхів у змінній середовища `Path` для поточного термінала програму вдалося запустити.

Також налаштовано кодування UTF-8 для правильного виведення українських символів.

### 4.2. Створення проєкту

Створено проєкт `Lab1_Apteka` з основними каталогами:

- `src/` — вихідний код програми;
- `data/` — вхідні CSV-файли;
- `out/` — результати компіляції та звіти;
- `ai/` — опис ролей ШІ.

Передбачено файли `README.md`, `REPORT.md`, `.gitignore`, `.gitattributes` та `.editorconfig`.

### 4.3. Реалізація програми

У файлі `src/Main.java` реалізовано:

- читання текстового файлу в кодуванні UTF-8;
- розділення записів на поля за символом `;`;
- перевірку кількості полів;
- перевірку текстових і числових значень;
- перевірку невід'ємності ціни та кількості днів;
- перевірку значень `true` і `false`;
- обробку некоректних записів без аварійного завершення;
- обчислення чотирьох показників;
- виведення результатів у консоль;
- збереження звіту в текстовий файл.

Програма підтримує параметри `--help`, `--input` та `--output`.

### 4.4. Компіляція та запуск

Команда компіляції:

```powershell
javac -encoding UTF-8 -d out src/Main.java
```

Команда запуску:

```powershell
java -cp out src.Main
```

Запуск із власними шляхами:

```powershell
java -cp out src.Main --input data/input.csv --output out/test.txt
```

### 7.5. Виявлені та виправлені помилки

**Помилка 1.** `UnsupportedClassVersionError`.

Причина: використання Java 8 для запуску програми, скомпільованої Java 21.

Виправлення: змінено шлях до виконуваного файлу Java для поточного термінала.

**Помилка 2.** Некоректне відображення українських символів.

Причина: невідповідність кодування термінала та Java.

Виправлення: налаштовано використання UTF-8. Під час роботи проблема повторювалася після зміни налаштувань термінала.

**Помилка 3.** Невдала спроба відправлення проєкту на GitHub.

Причина: у Git не були задані ім'я та email автора, тому перший коміт не створився.

Виправлення: налаштовано дані автора Git, створено коміт та виконано відправлення до репозиторію.
