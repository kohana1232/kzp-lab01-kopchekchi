
# Лабораторна робота №1

## Варіант 11 — Аптека

### Мета роботи
Створити консольну Java-програму для читання,
перевірки та обробки даних із CSV-файлу.

### Використані технології
- Java 21
- Visual Studio Code
- CSV (UTF-8)

### Структура проєкту
- src/Main.java — вихідний код програми
- data/input.csv — вхідні дані
- out/report.txt — файл результатів

### Формат вхідних даних
Кожен рядок містить п'ять полів:

name;form;price;daysToExpire;prescription

Приклад:
Парацетамол;Таблетки;45.50;300;false

Поля розділяються символом крапки з комою (;).
Дробові числа записуються через крапку.

### Компіляція
javac -encoding UTF-8 -d out src/Main.java

### Запуск
java -cp out src.Main

### Довідка
java -cp out src.Main --help

### Власний вхідний та вихідний файл
java -cp out src.Main --input data/input.csv --output out/test.txt

### Обчислювані показники
1. Кількість коректних записів.
2. Середня ціна препаратів.
3. Мінімальна кількість днів до завершення терміну придатності.
4. Кількість рецептурних препаратів.

### Перевірка даних
Програма перевіряє кількість полів, порожні значення,
правильність чисел, невід'ємність ціни та кількості днів,
а також значення true/false.

Некоректні записи пропускаються із повідомленням
про номер рядка та причину помилки.

### Результат для прикладу
Кількість коректних записів: 6
Середня ціна: 95.17 грн
Мінімум днів до завершення терміну: 30
Рецептурних препаратів: 2

Результати виводяться в консоль та записуються
у файл out/report.txt.

## Додаткові перевірки

Програму перевірено на таких випадках:
- шість коректних записів;
- некоректна від'ємна ціна;
- нечислове значення ціни;
- неправильне значення prescription;
- порожній вхідний файл.

Усі виконані перевірки пройдено успішно.

## Перевірка перед здачею

Проведено перевірку структури проєкту,
Java-коду, тестових даних та документації.

## Лабораторна робота №2

**Тема:** Класи, record і інкапсуляція в Java-проєкті  
**Варіант:** 11 — «Аптека»  
**Рівень:** 1

### Мета роботи

Рефакторинг програми лабораторної роботи №1 із використанням об'єктно-орієнтованого підходу, інкапсуляції, класів Java та record.

### Структура програми

- `src/Main.java` — головний клас, читання файлу, обчислення статистики та формування звіту.
- `src/Medicine.java` — клас лікарського препарату з приватними незмінними полями, конструктором, валідацією, геттерами, `fromCsv()` і `toString()`.
- `src/ExpiryPrescription.java` — допоміжний незмінний record для терміну придатності та рецептурності.
- `src/MedicineTest.java` — 10 програмних перевірок.
- `data/input.csv` — коректні вхідні дані.
- `data/errors.csv` — дані з помилками.
- `data/empty.csv` — порожній набір даних.

### Компіляція

```powershell
javac -encoding UTF-8 -d out src/Main.java src/Medicine.java src/ExpiryPrescription.java src/MedicineTest.java
```

### Запуск

```powershell
java -cp out src.Main
```

### Запуск перевірок

```powershell
java -cp out src.MedicineTest
```

### Результати

Для стандартного файлу `input.csv`:

- Коректних записів: 6.
- Середня ціна: 95.17 грн.
- Мінімум днів до завершення терміну: 30.
- Рецептурних препаратів: 2.

Програма зберігає результати лабораторної №1 після переходу до об'єктної моделі.

### Тестування

Усі 10 програмних перевірок завершилися успішно. Перевірено коректний CSV, порожню назву, від'ємну ціну, неправильне число, record, від'ємний термін, нульові значення, null, NaN та неправильний boolean.

Перевірки реалізовані без JUnit. Maven Wrapper, JUnit 5 та CI наразі не налаштовані.
